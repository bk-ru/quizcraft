# Дизайн HTML-документации диаграмм

## Цель

Преобразовать `docs/diagrams/класс.md` и `docs/diagrams/компонентов.md` в две самостоятельные HTML-страницы:

- `docs/diagrams/класс.html`;
- `docs/diagrams/компонентов.html`.

HTML должен открываться напрямую с диска без сборки, сервера, JavaScript-зависимостей и подключения внешних ресурсов.

## Аудитория

Разработчики, преподаватели и проверяющие, которым нужно изучить архитектуру QuizCraft в браузере или распечатать документацию.

## Визуальное направление

Техническая документация в стиле архитектурного справочника:

- светлый нейтральный фон;
- тёмная типографика с синим акцентом;
- фиксированная боковая навигация на широких экранах;
- компактное верхнее меню на мобильных устройствах;
- карточки для описания классов и компонентов;
- таблицы с горизонтальной прокруткой на узких экранах;
- визуально различимые блоки «Назначение», «Состояние», «Операции» и «Зависимости».

Шрифты используются системные, чтобы страницы работали автономно.

## Структура страниц

Каждая страница содержит:

1. заголовок и краткое описание диаграммы;
2. ссылку на исходный `.drawio` и соседнюю HTML-страницу;
3. автоматически сформированное оглавление по заголовкам второго и третьего уровня;
4. полный текст соответствующего Markdown-документа;
5. якоря у разделов;
6. кнопку возврата наверх;
7. footer с именем исходного файла.

## Реализация

- Содержимое Markdown переносится без сокращений.
- Обе страницы используют одинаковый встроенный CSS.
- CSS и минимальный JavaScript находятся внутри каждого HTML-файла.
- JavaScript используется только для мобильного оглавления и кнопки возврата наверх.
- Внешние CDN, web fonts и изображения не используются.
- Русские имена файлов и текст сохраняются в UTF-8.

## Адаптивность

- Desktop: двухколоночная сетка с боковым оглавлением.
- Tablet: более узкое оглавление и уменьшенные поля.
- Mobile: одна колонка, сворачиваемое оглавление, прокручиваемые таблицы.

## Печать

В `@media print` скрываются навигация и интерактивные элементы, убираются декоративные тени, раскрывается весь контент и сохраняются читаемые границы таблиц.

## Проверка

- оба HTML-файла существуют и декодируются как строгий UTF-8;
- HTML содержит `<!doctype html>`, `lang="ru"`, `<meta charset="utf-8">`;
- все заголовки и таблицы из Markdown представлены в HTML;
- ссылки на `.drawio` и соседнюю страницу разрешаются локально;
- отсутствуют внешние `http://` и `https://` ресурсы;
- страницы проверяются в desktop- и mobile-размерах браузера;
- печатное оформление не скрывает основное содержимое.

## Вне области задачи

- изменение исходных Markdown и draw.io-файлов;
- встраивание интерактивного просмотра самой draw.io-диаграммы;
- публикация страниц на GitHub Pages;
- добавление поискового индекса по проекту.
